# Landing Page Copywriter

Write conversion-focused landing page copy that turns visitors into leads and buyers.

## Core Philosophy

Simple pages with focused messaging consistently outperform fancy designs. Every element must earn its place by driving toward conversion.

## Workflow

### 1. Gather Context

Before writing, understand:
- **The offer**: What are they getting? (Lead magnet, course, service, product)
- **The audience**: Who is this for? What's their current pain?
- **The transformation**: Where are they now → where will they be after?
- **The mechanism**: How does this offer deliver the result?

### 2. Write the Core Elements

**Headline**: The most important element. Must communicate the main benefit or solve a specific problem. Use curiosity, specificity, or direct benefit.

Headline formulas:
- "Free [Resource] Reveals [Desirable Outcome]"
- "How to [Achieve Result] Without [Pain Point]"
- "The [Adjective] Way to [Benefit]"
- "[Number] [Things] That [Create Result]"

**Subheadline**: Supports and clarifies the headline. Adds detail or addresses a secondary benefit/objection.

**Body Copy**: Use the Bridge Framework:
1. WHO this is for (call out the reader)
2. WHERE they are now (current pain, frustration)
3. WHERE they'll be after (desired outcome)
4. HOW this gets them there (mechanism)
5. WHEN they can start (immediacy)

**Bullets**: Transform features into benefits. Each bullet should create desire or address an objection. Use specificity and concrete outcomes.

**CTA**: Action-oriented, specific, and benefit-focused.
- Weak: "Submit" / "Sign Up"
- Strong: "Get Instant Access" / "Download My Free Guide" / "Reserve My Spot"

### 4. Quality Check

Before finalizing:
- [ ] Headline communicates clear benefit or solves specific problem
- [ ] Copy focuses on ONE primary action
- [ ] Benefits outweigh features
- [ ] Objections are addressed
- [ ] CTA is repeated and visible
- [ ] No competing links or distractions
- [ ] Language matches audience's own words

Consult `references/ai-giveaway-blacklist.md` — never use banned words/phrases.

## Page Types

### Opt-in Pages (Lead Magnets)
- Ultra-simple: headline, 3-5 bullets, form, CTA
- Promise ONE clear outcome
- Reduce friction (name + email only, or email only)
- Show the lead magnet visually if possible

### Sales Pages
- Longer format, more objection handling
- Include: headline, problem, agitation, solution, benefits, proof, offer, guarantee, CTA
- Multiple CTAs throughout
- Testimonials and case studies near decision points

### Webinar/Event Registration
- Focus on what they'll learn/get
- Include date/time prominently
- Urgency through limited spots or time-sensitivity
- Brief host credibility

## Output Format

When delivering landing page copy, provide:
1. **Headline options** (2-3 variations)
2. **Subheadline**
3. **Body copy** (structured by section)
4. **Bullet points** (if applicable)
5. **CTA text**
6. **Notes** on placement or design considerations (brief)
